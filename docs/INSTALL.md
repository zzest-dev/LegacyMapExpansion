# Установка Legacy Map Expansion 1.0.0

Готовый выпуск доступен на [странице релиза 1.0.0](https://github.com/zzest-dev/LegacyMapExpansion/releases/tag/v1.0.0). Скачайте **LegacyMapExpansion-1.0.0.zip** из раздела Assets.

1. Установите BepInEx 5 в MadOut2 PC 9.4 и один раз запустите игру.
2. Закройте игру. Распакуйте содержимое архива в корень игры, рядом с исполняемым файлом. Вложенная папка `BepInEx` объединится с установленной.
3. Проверьте, что в `plugins` нет второй DLL этого плагина, и запустите игру.

При обновлении замените прежнюю DLL при закрытой игре. В установочном архиве находятся `BepInEx/plugins/LegacyMapExpansion/LegacyMapExpansion.dll` и инструкция `README.md`. Такой архив подходит для установщика, который распаковывает файлы в корень игры. Контрольная сумма архива опубликована в `SHA256SUMS.txt` на странице релиза.

Дополнительные бандлы рядом с DLL не нужны: ресурсы встроены внутрь сборки. Файлы карты в папке игры вручную менять не требуется.

В журнале `BepInEx/LogOutput.log` должны появиться сообщения `Map expansion ready` и при чтении карты `Map data override active`. Первое подтверждает готовность ресурсов, второе — использование подменённого бинарника через штатный загрузчик MapPro.

Плагин регистрируется под идентификатором `com.bigcitylegacy.map1018`. Этот идентификатор используется для конфигурации. Ресурсы выпуска включают выбранные локации 10.24.

Для отключения измените `General.Enabled = false` в конфигурации BepInEx плагина и перезапустите игру либо удалите DLL при закрытой игре. Изменение настройки применяется при следующем запуске.

## Если что-то не загрузилось

| Сообщение или симптом | Что проверить |
| --- | --- |
| `Unsupported base map` | Хеш карты не совпадает с поддерживаемой PC 9.4. Сверьте `Resources/compatibility.json` в исходниках; не обходите проверку вслепую |
| `Missing map resource` | Установлена неполная или неправильно собранная DLL |
| `Native ground material unavailable` | Не найден штатный материал; плагин оставляет исходный тайл, чтобы не подставить белый рельеф |
| Плагин отсутствует в журнале | Проверьте установку BepInEx, папку DLL и настройку Enabled |
| Две версии локации одновременно | Исключите дубликаты плагина и другие модификации тех же GUID/карты |

Для сетевой игры обновите плагин на сервере и клиентах до актуальной пересборки 1.0.0. Сервер не создаёт игрока до подтверждения совместимой карты; старый плагин 1.0.0 без сетевой проверки также потребует обновления. Проверяется не только номер версии, но и идентификатор содержимого карты. Подробности: [NETWORK.md](NETWORK.md). Этот плагин не добавляет сетевой протокол синхронизации разрушений и не переносит серверные скрипты новых версий.
