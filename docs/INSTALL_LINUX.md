# Legacy Map Expansion 1.0.0 для Linux

Архив `LegacyMapExpansion-1.0.0-Linux.zip` содержит отдельную сборку плагина с ресурсами Unity для Linux x86_64. Карта и версия 1.0.0 совпадают с Windows-релизом. Архив подходит для Linux-клиента и Linux-сервера MadOut2 PC 9.4 с BepInEx 5 и Mono.

1. Остановите сервер.
2. Сохраните прежнюю DLL плагина, если она установлена.
3. Распакуйте содержимое архива в корень каталога сервера. DLL окажется в `BepInEx/plugins/LegacyMapExpansion/LegacyMapExpansion.dll`.
4. Убедитесь, что в `plugins` осталась ровно одна `LegacyMapExpansion.dll`, и запустите сервер обычной командой.

Не устанавливайте Windows-DLL на Linux и не копируйте Linux-DLL Windows-клиентам. Все ресурсы встроены в DLL; отдельная замена `StreamingAssets/Map.bytes` не требуется. BepInEx и игровые библиотеки в архив не входят.

В `BepInEx/LogOutput.log` проверьте сообщения `Map expansion ready` и `Map data override active`. При ошибке `Unsupported base map` исходная карта сервера отличается от поддерживаемой PC 9.4; потребуется проверить версию сервера. Не обходите проверку хеша.

Для совпадения геометрии и коллизий используйте одинаковую карту на сервере и клиентах: Windows-клиентам нужна Windows-сборка, Linux-серверу — архив с суффиксом `-Linux`. Плагин не проверяет наличие карты у игроков и не блокирует подключения к обычным серверам. Обязательная сетевая проверка из предыдущей пересборки удалена; для отката замените DLL и перезапустите сервер. Старые настройки `[Network]` больше не используются.

Для отката остановите сервер и верните сохранённую DLL либо удалите плагин.
